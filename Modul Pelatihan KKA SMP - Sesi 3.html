Sesi 3: Konsep Dasar

Konsep Dasar Percabangan Program

Secara normal, komputer menjalankan baris kode secara lurus berurutan dari atas ke bawah. Namun, program sering kali harus memberikan hasil yang berbeda tergantung pada tindakan pengguna.

Logika Percabangan (*Conditional Logic*) memungkinkan program untuk mengecek suatu syarat, kemudian memutuskan baris kode mana yang harus dijalankan dan mana yang harus dilewati.

Sesi 3: Tipe Data

Tipe Data Boolean (Benar / Salah)

Setiap pengecekan syarat pada program komputer hanya akan menghasilkan dua kemungkinan, yaitu Benar atau Salah. Dalam pemrograman, ini disebut tipe data Boolean.

True

Syarat terpenuhi. Program akan menjalankan perintah.

False

Syarat tidak terpenuhi. Program akan mengabaikan perintah.

Aturan Penulisan Python: Kata True dan False wajib diawali dengan huruf kapital. Jika ditulis true (huruf kecil semua), program akan mengalami galat (*error*).

Sesi 3: Percabangan Dasar

Struktur Percabangan Tunggal: if

Perintah if berfungsi seperti penjaga pintu. Perintah-perintah yang berada di bawahnya hanya akan dijalankan jika syarat bernilai True.

Aturan Menulis Percabangan:

Akhiri baris if dengan tanda titik dua (:). Baris perintah di bawahnya wajib diberi jarak spasi ke dalam (Indentasi).

cuaca = "Hujan"

if cuaca == "Hujan":
    # Baris ini harus bergeser ke kanan (di-Tab)
    print("Sedia payung sebelum keluar.")
    print("Jalanan mungkin licin.")
    
# Baris yang sejajar di kiri akan selalu dijalankan
print("Program selesai.")
Sesi 3: Tips Mengajar

Analogi Pembelajaran: "Lemari Laci"

Siswa SMP akan mudah mengerti konsep spasi ke dalam (indentasi) menggunakan analogi Lemari Laci:

Anggap tulisan if sebagai bingkai laci lemari. Jika kita menekan tombol *Tab* atau spasi ke kanan, itu berarti kita memasukkan barang-barang (perintah kode) ke dalam laci tersebut.

Jika syarat tidak terpenuhi (laci terkunci), maka komputer tidak akan pernah bisa membaca apalagi menjalankan perintah yang ada di dalam laci tersebut.

Sesi 3: Dua Kemungkinan

Dua Pilihan Kondisi: if - else

Jika syarat if tidak terpenuhi (False), program secara otomatis akan melompati perintah tersebut. Namun, terkadang kita perlu memberikan instruksi alternatif.

Perintah else digunakan sebagai jalan keluar lain jika kondisi if gagal terpenuhi.

if syarat_terpenuhi:
    # Perintah jika syarat Benar (True)
    jalankan_perintah_A()
else:
    # Perintah jika syarat Salah (False)
    jalankan_perintah_B()
Sesi 3: Praktik

Praktik Level Menengah: Cek Kelulusan Siswa

kelulusan.py 
kkm_sekolah = 75
nilai_ujian = int(input("Masukkan nilai ujian siswa: "))

if nilai_ujian >= kkm_sekolah:
    print("Status: TUNTAS")
    print("Siswa dapat mengikuti program pengayaan.")
else:
    print("Status: BELUM TUNTAS")
    print("Siswa dijadwalkan mengikuti remedial.")

Instruksi Modifikasi (*Tweak*):

Ubah tanda >= menjadi tanda >. Mintalah peserta memasukkan angka pas 75. Diskusikan mengapa angka 75 sekarang dianggap belum tuntas.

Sesi 3: Banyak Kondisi

Pemeriksaan Banyak Kondisi: elif (Else-If)

Dalam dunia nyata, keputusan sering kali tidak hanya "Ya" atau "Tidak". Jika terdapat banyak kemungkinan, kita menggunakan fungsi elif.

Penting: Komputer memeriksa syarat dari atas ke bawah. Saat ia menemukan satu syarat yang bernilai True, ia akan menjalankan blok tersebut lalu langsung keluar tanpa mengecek syarat-syarat di bawahnya lagi.

Sesi 3: Kondisi Bersarang

Percabangan Bersarang (Nested If)

Beberapa aplikasi membutuhkan pemeriksaan ganda. Contohnya, sistem mengecek *username* terlebih dahulu, jika benar, barulah sistem mengecek *password*.

Penulisan `if` di dalam `if` disebut Percabangan Bersarang.

Fokus Mengajar:

Beri perhatian khusus pada jarak spasi (indentasi). Kondisi yang berada di dalam harus bergeser lebih jauh ke arah kanan dibandingkan kondisi luarnya.

Sesi 3: Membedah Galat

Menganalisis Kesalahan Spasi (IndentationError)

IndentationError: expected an indented block after 'if' statement on line 3

Solusi Penanganan Siswa:

Galat ini muncul ketika baris setelah if lupa diberi jarak spasi ke dalam (Indentasi). Ajarkan siswa untuk menghapus spasi yang berantakan, kembali ke tanda titik dua (:), lalu tekan Enter agar aplikasi otomatis mengatur jaraknya dengan rapi.

Sesi 3: Rangkuman

Rangkuman Capaian Pembelajaran Sesi 3

  • Tipe Data Boolean (True/False) adalah landasan utama dalam pengambilan keputusan di komputer.
  • Syarat diperiksa menggunakan operator perbandingan matematika (==, >, <).
  • Python menyediakan instruksi if, elif, dan else untuk menangani kemungkinan-kemungkinan hasil dari sebuah syarat.
  • Jarak tulisan (Indentasi) bukanlah hiasan, melainkan aturan ketat yang menyatukan blok kode pada Python.
