Sesi 5: Konsep Modularitas

Mengapa Kita Membutuhkan Fungsi?

Ketika proyek aplikasi mulai membesar hingga menyentuh ratusan baris, menyusun kode dari atas ke bawah secara linear akan menciptakan kekacauan logika (*Spaghetti Code*).

Modularitas adalah teknik memecah program besar menjadi bagian-bagian kecil (modul/fungsi) yang spesifik, mandiri, dan dapat dipanggil kapan saja tanpa perlu menulis ulang baris kodenya.

Sesi 5: Deklarasi Fungsi

Anatomi Pembuatan Fungsi: def

Di dalam ekosistem Python, penciptaan sebuah fungsi diawali dengan kata kunci def (singkatan dari *define* atau mendefinisikan).

# 1. Mendefinisikan Fungsi (Pembuatan Modul)
def sapa_sekolah():
    # Semua yang menjorok ke dalam adalah milik fungsi ini
    print("Selamat datang di Laboratorium Komputer.")
    print("Harap mematuhi tata tertib penggunaan gawai.")
    print("--- Modul KKA Aktif ---")

# Catatan: Baris kode di atas TIDAK AKAN dieksekusi 
# jika fungsinya tidak dipanggil secara spesifik.
Sesi 5: Pemanggilan Fungsi

Mengaktifkan Modul: Pemanggilan (Call)

Fungsi bertindak pasif hingga dipanggil. Pemanggilan dilakukan dengan menulis nama fungsi tersebut diikuti sepasang tanda kurung ().

Pendekatan Analogi:

Gunakan metafora "Tombol Mesin". Menulis def sama dengan merakit mesin baru. Sedangkan menulis nama_fungsi() sama dengan menekan tombol daya untuk menyalakan mesin tersebut.

# Merakit Mesin
def cetak_peringatan():
    print("Peringatan: Kapasitas memori penuh!")

# Menekan tombol (Bisa berkali-kali)
cetak_peringatan()
cetak_peringatan()
Sesi 5: Asupan Data

Memasukkan Bahan Mentah: Parameter

Fungsi yang dinamis membutuhkan data masukan untuk diolah. Variabel penampung di dalam tanda kurung fungsi disebut Parameter.

fungsi_parameter.py 
# 'nama_siswa' adalah parameter yang siap menerima data
def sapa_personal(nama_siswa):
    print(f"Halo, {nama_siswa}! Selamat belajar Python.")

# 'Andi' dan 'Siti' adalah argumen (data nyata yang disetor)
sapa_personal("Andi")
sapa_personal("Siti")
Sesi 5: Multi-Parameter

Memasukkan Banyak Data Sekaligus

Sistem mengizinkan kita memasukkan lebih dari satu asupan data ke dalam fungsi, cukup dengan memisahkannya menggunakan tanda koma (,).

Posisi penyetoran data (argumen) wajib berurutan sesuai dengan tempat yang disediakan oleh parameter.

def laporan_nilai(nama, mata_pelajaran, skor):
    print("--- Transkrip Siswa ---")
    print(f"Siswa: {nama}")
    print(f"Nilai {mata_pelajaran}: {skor}")

# Penyetoran harus berurutan
laporan_nilai("Budi", "Matematika", 85)
Sesi 5: Hasil Pemrosesan

Mengekstraksi Hasil Akhir: Kata Kunci return

Dalam rekayasa perangkat lunak profesional, fungsi yang bertugas menghitung (algoritmik) idealnya tidak boleh langsung mencetak tulisan ke layar menggunakan print(). Mereka harus mengembalikan nilai hasil perhitungannya kepada baris kode yang memanggilnya.

Perintah return digunakan untuk melempar (mengembalikan) hasil operasi keluar dari ruang lingkup fungsi.

Sesi 5: Praktikum Return

Praktik Level Menengah: Modul Konversi Suhu

konversi_suhu.py 
# Fungsi fokus pada operasi aritmatika murni
def ubah_celcius_ke_fahrenheit(celcius):
    suhu_f = (celcius * 9/5) + 32
    return suhu_f  # Melempar angka hasil

# Alur Utama Program
suhu_ruangan = float(input("Berapa derajat celcius saat ini? "))

# Menangkap hasil lemparan (return) ke dalam wadah variabel baru
suhu_hasil = ubah_celcius_ke_fahrenheit(suhu_ruangan)

print(f"Apabila dikonversi, suhu ruangan adalah {suhu_hasil} Fahrenheit.")
Sesi 5: Isolasi Variabel

Pemahaman Ruang Lingkup (Scope): Lokal vs Global

Penting bagi siswa untuk memahami batas privasi data:

  • Variabel Lokal: Segala variabel yang diciptakan di dalam def akan musnah segera setelah fungsi selesai bertugas. Komputer tidak akan mengingatnya di luar blok fungsi.
  • Variabel Global: Diciptakan di luar fungsi, dan dapat dibaca oleh seluruh elemen di dalam program tersebut.

def modul_ai_penjurusan(bakat):
    if bakat == "Logika":
        return "Klub Robotika KKA siap menampung bakat Anda."
    elif bakat == "Fisik":
        return "Tim Basket Sekolah menanti kehadiran Anda."

        return "Silakan konsultasi lebih lanjut dengan Guru Bimbingan Konseling."

hasil_rekomendasi = modul_ai_penjurusan(bakat_utama)

print(f"\nRingkasan Evaluasi untuk {nama_siswa}:")
