Sesi 4: Konsep Dasar

Prinsip D.R.Y (Don't Repeat Yourself)

Salah satu kaidah utama dalam rekayasa perangkat lunak adalah efisiensi. Jika sebuah program membutuhkan penulisan baris kode yang persis sama sebanyak tiga kali atau lebih, maka terdapat masalah pada struktur algoritma tersebut.

Perulangan (Looping) adalah instruksi yang meminta komputer menjalankan sebuah blok kode berkali-kali secara otomatis, hingga batas waktu atau syarat tertentu tercapai.

Sesi 4: Jenis Perulangan

Dua Kategori Perulangan di Python

Sistem Python menyediakan dua perintah perulangan utama yang digunakan untuk skenario berbeda:

Perulangan FOR

Digunakan ketika kita sudah mengetahui dengan pasti berapa kali proses harus diulang.

Contoh: Mencetak nomor absen 1 sampai 30.

Perulangan WHILE

Digunakan ketika kita tidak tahu berapa putaran yang dibutuhkan, tetapi proses hanya berhenti saat syarat dipenuhi.

Contoh: Meminta password sampai diketik benar.

Sesi 4: Perulangan FOR

Perulangan Terukur: Fungsi for

Untuk menjalankan perulangan dengan jumlah hitungan tertentu, perintah for umumnya disandingkan dengan fungsi bantuan bernama range().

# Format dasar: untuk setiap angka di dalam rentang
for angka in range(1, 4):
    print("Siswa hadir nomor:", angka)

# Hasil cetakan di layar:
# Siswa hadir nomor: 1
# Siswa hadir nomor: 2
# Siswa hadir nomor: 3
Sesi 4: Fungsi Range

Memahami Batas Fungsi range()

Aturan Penting range():

Fungsi range(awal, akhir) akan memulai hitungan dari angka "awal", namun selalu berhenti satu angka sebelum angka "akhir".

  • range(1, 10) akan menghitung angka 1 sampai 9.
  • range(5) akan menghitung 5 kali (dimulai dari 0, 1, 2, 3, 4).
Sesi 4: Praktik Mudah

Praktik Level Mudah: Mencetak Kartu Antrean

antrean.py 
jumlah_peserta = int(input("Berapa peserta yang hadir? "))

print("\nMemulai pencetakan nomor antrean...")

# Tambahkan +1 agar hitungan berhenti tepat di angka jumlah_peserta
for urutan in range(1, jumlah_peserta + 1):
    print(f"Mencetak Tiket: {urutan}")

print("Pencetakan selesai.")
Sesi 4: Praktik Menengah

Praktik Level Menengah: Generator Tabel Perkalian

perkalian.py 
angka_dasar = int(input("Masukkan angka perkalian: "))

print(f"--- Tabel Perkalian {angka_dasar} ---")

for i in range(1, 11):
    hasil = angka_dasar * i
    print(f"{angka_dasar} x {i} = {hasil}")

Arah Bimbingan: Latihan ini menunjukkan keunggulan perulangan. Daripada menulis rumus manual sebanyak sepuluh baris, kita dapat menggunakan variabel i yang bertambah nilainya secara otomatis (1 hingga 10) di setiap putaran.

Sesi 4: Perulangan WHILE

Perulangan Bersyarat: Fungsi while

Perintah while bekerja persis seperti perintah if, tetapi dengan kemampuan mengulang. Baris kode akan terus diulang selama kondisinya tetap bernilai True.

bensin = 3

while bensin > 0:
    print("Mesin menyala.")
    # Penting: Bensin harus dikurangi agar perulangan bisa berhenti
    bensin = bensin - 1 

print("Mesin mati kehabisan bensin.")
Sesi 4: Aturan WHILE

Syarat Berhenti (Exit Condition)

Perulangan while sangat rawan menimbulkan masalah jika kita melupakan mekanisme untuk mengubah kondisi.

Siswa harus diajarkan untuk selalu menyertakan baris pembaruan variabel di dalam blok while (seperti nilai = nilai - 1 atau jawaban = input(...)).

Jika nilai tidak pernah diubah, kondisi akan selamanya bernilai True.

Sesi 4: Analisis Galat

Bahaya Perulangan Abadi (Infinite Loop)

Contoh Kasus Kesalahan:

# Kode ini akan membuat komputer macet (hang)
angka = 5
while angka > 0:
    print("Mencetak tulisan abadi...")
    # Siswa lupa menaruh kode pengurangan angka

Solusi Mengajar:

Jika hal ini terjadi di kelas, jangan biarkan siswa panik. Ajarkan mereka untuk memencet tombol kombinasi CTRL + C (*Keyboard Interrupt*) secara bersamaan pada papan tik (*keyboard*) untuk menghentikan program yang macet secara paksa.

Sesi 4: Praktik Mudah

Praktik Level Mudah: Penghitung Waktu Mundur

waktu_mundur.py 
import time # Modul untuk memberikan jeda waktu

waktu_tersisa = int(input("Atur waktu mundur (detik): "))

while waktu_tersisa > 0:
    print(f"Waktu tersisa: {waktu_tersisa} detik")
    time.sleep(1) # Berhenti sejenak selama 1 detik
    
    # Kurangi waktu tersisa agar perulangan bisa berhenti
    waktu_tersisa = waktu_tersisa - 1 

print("Waktu habis!")
Sesi 4: Praktik Menengah

Praktik Level Menengah: Memaksa Validasi Jawaban

Perulangan while sangat cocok digunakan untuk mengunci pengguna di layar jika ia memberikan jawaban yang keliru.

validasi_sandi.py 
kata_sandi = ""

# Program akan terus bertanya selama sandi belum "KKA2026"
while kata_sandi != "KKA2026":
    kata_sandi = input("Masukkan kata sandi rahasia: ")
    
    if kata_sandi != "KKA2026":
        print("Sandi salah. Coba lagi.\n")

print("\nAkses disetujui. Selamat masuk ke sistem.")
Sesi 4: Kontrol Lanjutan

Memutus Perulangan Secara Paksa: break

Terkadang kita perlu menghentikan putaran sebelum mencapai batas akhirnya (misalnya: jika sebuah pencarian telah menemukan hasil yang diinginkan).

Perintah break akan menghancurkan blok perulangan secara instan, dan program akan melompat keluar melanjutkan baris kode di bawahnya.

for angka in range(1, 10):
    if angka == 5:
        print("Ketemu angka 5! Berhenti sekarang.")
        break
    print("Mengecek angka:", angka)

print("Keluar dari blok perulangan.")
Sesi 4: Kontrol Lanjutan

Melompati Satu Putaran: continue

Berbeda dengan break yang menghancurkan seluruh putaran, perintah continue hanya mengabaikan sisa instruksi pada putaran saat itu saja, dan langsung melompat ke putaran angka berikutnya.

for angka in range(1, 6):
    if angka == 3:
        print("Angka 3 dilewati.")
        continue
        
    print("Mencetak angka:", angka)
    
# Hasilnya: 1, 2, (3 dilewati), 4, 5
Sesi 4: Konsep Kompleks

Perulangan Bersarang (Nested Loop)

Dalam materi tingkat lanjut, kita dapat meletakkan perulangan for di dalam perulangan for yang lain. Ini digunakan untuk menyelesaikan masalah yang memiliki dua dimensi (seperti baris dan kolom).

Logika Putaran: Perulangan bagian dalam harus diselesaikan secara penuh (100%) untuk setiap satu kali putaran pada perulangan luar.

Sesi 4: Praktik Sulit

Praktik Level Sulit: Membuat Pola Bintang

pola_bintang.py 
tingkat = int(input("Masukkan jumlah baris pola: "))

# Perulangan luar: Mengatur jumlah baris vertikal
for baris in range(1, tingkat + 1):
    simbol = ""
    
    # Perulangan dalam: Mengisi kolom horizontal pada baris saat itu
    for kolom in range(baris):
        simbol = simbol + "★ "
        
    print(simbol)

Catatan: Kode di atas akan mencetak pola segitiga bintang yang ukurannya sesuai dengan angka yang dimasukkan pengguna.

Sesi 4: Catatan Pedagogi

Membedah Kesulitan Belajar Siswa pada Nested Loop

Diagnosa Pemahaman Siswa:

Perulangan bersarang adalah materi tersulit bagi siswa Fase D. Hal ini disebabkan karena mereka kesulitan melacak dua variabel hitungan secara bersamaan di dalam kepala mereka.

Tips Fasilitasi: Jangan hanya menjelaskan secara lisan. Gunakan tabel di papan tulis untuk menuliskan langkah demi langkah nilai variabel baris dan variabel kolom yang sedang terjadi pada saat putaran tersebut berlangsung.

Sesi 4: Rangkuman

Rangkuman Capaian Pembelajaran Sesi 4

  • Struktur Perulangan diciptakan untuk menjalankan tugas repetitif secara efisien (Prinsip D.R.Y).
  • Perintah for digabungkan dengan range() bila batas putaran program telah diketahui secara pasti.
  • Perintah while bertindak seperti pengkondisian yang berulang; putaran berhenti saat syarat sudah tidak terpenuhi.
  • Kewaspadaan terhadap ketiadaan mekanisme pengubah syarat (exit condition) diperlukan untuk menghindari perulangan abadi (Infinite Loop).
