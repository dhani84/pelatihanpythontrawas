Sesi 2: Fungsi Keluaran

Fungsi Proyeksi Visual: print()

Fungsi print() adalah metode absolut Python untuk mengomunikasikan informasi (teks atau angka) dari mesin (komputer) kembali ke layar pengguna.

Aturan Sintaksis Fundamental:

  • Menggunakan huruf kecil seutuhnya (*case sensitive*).
  • Nilai teks (String) wajib diapit tanda kutip tunggal '...' atau ganda "...".
  • Nilai numerik matematis (Angka) tidak memerlukan tanda kutip.
keluaran_layar.py 
# Proyeksi Teks Literal
print("Sistem KKA diinisialisasi.")
print('Menunggu instruksi pengguna...')

# Proyeksi Nilai Numerik
print(2026)

# Proyeksi Hasil Komputasi Langsung
print(50 + 25)
Sesi 2: Fungsi Keluaran

Konsistensi Pembatas Literal (Kutip)

Salah satu galat paling umum bagi siswa pemula adalah inkonsistensi pembatas teks.

Valid (Sintaks Benar)

# Sepasang kutip ganda
print("Kalimat ini benar.")

# Sepasang kutip tunggal
print('Kalimat ini juga benar.')

# Kutip ganda mengapit kutip tunggal
print("Ini hari Jum'at.")

Invalid (Galat Sintaks)

# Terlupa kutip penutup
print("Ini akan error.)

# Penggunaan jenis kutip silang
print("Format ini salah.')

Akan memicu pesan peringatan: SyntaxError: unterminated string literal

Sesi 2: Ruang Memori

Konsep Variabel: Wadah Penyimpanan Sistem

Variabel adalah label yang diberikan pada sebuah ruang memori di dalam perangkat komputer. Ruang ini digunakan untuk menampung satu nilai spesifik yang dapat diubah atau dipanggil kapan saja (*Mutable*).

Arah Aliran Data (Penting!):
Simbol = (sama dengan) dalam pemrograman berfungsi sebagai Operator Penugasan (*Assignment Operator*), bukan hasil kesamaan matematika. Data mengalir dari kanan ke kiri.

Anatomi Deklarasi

nama_variabel = "Nilai Data"

(Kotak Penyimpanan) ← (Isi yang dimasukkan)

Sesi 2: Ruang Memori

Standar Penamaan Variabel (Naming Convention)

Sistem bahasa Python menerapkan restriksi yang ketat terhadap pembentukan identitas variabel untuk mencegah ambiguitas pemrosesan kode.

Kaidah FundamentalValid (Diterima)Invalid (Ditolak)
Tanpa Karakter Spasi
Gunakan garis bawah (*underscore*) sebagai pemisah.		 nama_siswa = "Budi" nama siswa = "Budi"
Larangan Angka di Depan
Angka diperbolehkan asal bukan karakter pertama.		 peserta_1 = "Siti" 1_peserta = "Siti"
Bebas Simbol Khusus
Hindari tanda hubung, bintang, atau karakter unik.		 skor_akhir = 90 skor-akhir = 90
Sesi 2: Fungsi Masukan

Fungsi Pendengaran Sistem: input()

Fungsi input() menangguhkan eksekusi baris program ke bawah dan memerintahkan komputer untuk menunggu intervensi tombol Enter dari pengguna.

Teks yang ditulis di dalam fungsi tersebut akan diproyeksikan sebagai instruksi visual (*prompt*).

masukan_pengguna.py 
# Menangkap data dan menyimpannya ke memori
identitas_user = input("Mohon ketik nama Anda: ")

# Mengekstrak memori ke layar terminal
print("Sistem mencatat identitas berikut:")
print(identitas_user)

Sesi 2: Penggabungan Data

Integrasi Teks (String Concatenation)

Mencetak respons baris demi baris menggunakan print() yang terpisah tidak merepresentasikan alur dialog yang dinamis. Python mengakomodasi perangkaian teks statis dan nilai variabel secara horisontal.

Metode Operator Tambah (+)

Menyambung string secara mutlak tanpa celah.

nama = "Budi"
# Spasi harus diketik manual di dalam kutip
print("Selamat datang " + nama + " di kelas KKA.")

Metode Operator Koma (,)

Secara otomatis menyisipkan jarak pemisah satu spasi.

nama = "Siti"
# Spasi dihasilkan otomatis oleh koma
print("Sistem mengenali pendaftar", nama)

Sesi 2: Literasi Galat

Membedah Galat Kritis: NameError

NameError: name 'Pengguna_aktif' is not defined. Did you mean: 'pengguna_aktif'?

Diagnosa Pemecahan Masalah Siswa:

Galat NameError mendominasi kegagalan skrip pada pekan pertama pembelajaran. Edukasi peserta didik untuk menginvestigasi tiga kemungkinan berikut:

  1. Ejaan Tidak Presisi (Typo): Pengetikan nama variabel yang berbeda satu karakter saja dengan saat deklarasi.
  2. Sensitivitas Kapitalisasi: Pemanggilan Nama, NAMA, dan nama dianggap sebagai tiga wadah yang sama sekali berbeda oleh mesin Python.
  3. Pemanggilan Prematur: Menggunakan variabel di baris 2, padahal variabel tersebut baru diciptakan (dideklarasikan) di baris 5.
Sesi 2: Format Lanjutan

Paradigma Modern: Interpolasi Format String (F-String)

Mulai Python versi 3.6, para insinyur perangkat lunak meninggalkan operator tambah (+) untuk menyambung teks karena rawan memicu kekacauan spasi, dan beralih menggunakan Format String (F-String).

Sintaks ini membubuhkan alfabet f sebelum tanda kutip pembuka, memungkinkan injeksi variabel secara langsung ke dalam tubuh kalimat menggunakan kurung kurawal {}.

kota_asal = "Malang"
provinsi = "Jawa Timur"

# Metode Lama (Rentan galat spasi)
print("Saya dari " + kota_asal + ", " + provinsi + ".")

# Metode Modern (F-String)
print(f"Saya dari {kota_asal}, {provinsi}.")
Sesi 2: Basis Data

Esensi Tipe Data Komputasional

Secara harfiah, angka "100" yang diserap mesin belum tentu dinilai sebagai entitas matematis yang dapat dieksekusi dalam kalkulasi. Komputer memperlakukan data berdasarkan klasifikasinya.

Klasifikasi PythonDeskripsi Fungsi TerapanContoh Nilai Literal
String (str) Kumpulan karakter alfanumerik. Merepresentasikan teks bacaan. Diapit tanda kutip. "100", "Siswa", "Rp 50.000"
Integer (int) Bentuk bilangan real bulat mutlak. Digunakan untuk perhitungan kuantitas. 100, -45, 0
Float (float) Bentuk bilangan desimal fraksional. Merepresentasikan presisi nilai. 3.14, 70.5, -0.5
Sesi 2: Literasi Konversi

Bahaya Logika Bawaan: Input is Always String

Aksioma Fundamental: Seluruh respons yang ditangkap oleh gerbang fungsi input() akan secara statis diklasifikasikan sebagai data String (Teks), tanpa terkecuali.

Demonstrasi Bahaya Logika:

# Asumsi pengguna mengetik 10 dan 20
nilai_a = input("Masukkan angka 1: ")
nilai_b = input("Masukkan angka 2: ")

hasil = nilai_a + nilai_b
print(hasil) 
# HASILNYA 1020, BUKAN 30!

Simbol + pada entitas string tidak menjumlahkan nilai, melainkan menempelkan kedua kalimat tersebut.

Sesi 2: Solusi Pemrosesan

Konversi Eksplisit Tipe Data (Type Casting)

Guna memfasilitasi operasi matematis, parameter input teks wajib dibungkus (di-casting) untuk diubah paksa formulasinya menjadi klasifikasi angka murni.

Implementasi Valid

# Membungkus instan pada tahap input
nilai_c = int(input("Masukkan bilangan: "))
nilai_d = int(input("Pengali: "))

# Variabel kini berstatus Integer matematis
kalkulasi_bersih = nilai_c * nilai_d
print(f"Hasil komputasi: {kalkulasi_bersih}")

Sistem Casting Utama:

  • int() mengonversi teks yang hanya berisi angka bulat menjadi Integer.
  • float() mengonversi teks angka menjadi format desimal akurat.
  • str() menarik nilai matematis kembali menjadi format teks biasa.
