Sesi 6: Objektif Praktikum

Fokus Proyek Akhir

Pembelajaran bahasa Python harus bermuara pada implementasi Kecerdasan Artifisial (KKA) sesuai kurikulum. Pada proyek puncak ini, kita akan membimbing siswa merakit sebuah Sistem Pakar Berbasis Aturan (Rule-Based Expert System). Aspek yang divalidasi meliputi:

  • Kecerdasan Artifisial Dasar: Merangkai fungsi (def) untuk bertindak sebagai Mesin Inferensi.
  • Multivariabel Logika: Mengoperasikan operator logika (and, or) pada struktur percabangan kompleks.
  • Siklus Otonom: Menerapkan perulangan while dengan mekanisme pencegahan penumpukan memori.
  • Integrasi Profil Lulusan: Mengembangkan algoritma untuk memetakan capaian "8 Dimensi Profil Lulusan".
Sesi 6: Konsep Dasar AI

Mendefinisikan Sistem Pakar (Expert System)

Sistem Pakar adalah cabang dari Kecerdasan Artifisial yang meniru kemampuan pengambilan keputusan seorang ahli (manusia). Arsitekturnya terdiri atas dua komponen yang akan kita bangun melalui kode Python:

  1. Basis Pengetahuan (Knowledge Base): Berisi fakta dan variabel yang diinput oleh pengguna.
  2. Mesin Inferensi (Inference Engine): Modul Fungsi (def) yang berisi aturan logika If-Else kompleks untuk menganalisis basis pengetahuan dan menghasilkan konklusi akhir.
Sesi 6: Dekonstruksi Produk

Aplikasi: AI Konselor Deteksi Minat Siswa

Skenario Produk: Kita akan menciptakan program yang mampu memberikan rekomendasi ekstrakurikuler atau peminatan secara spesifik. Program akan memberikan tiga pertanyaan diagnostik yang hanya dijawab dengan "Ya" atau "Tidak".

📥

Input (Sensor)

Menangkap 3 Variabel Jawaban (Ya/Tidak)

⚙️

Modul Fungsi (AI)

Menganalisis kombinasi jawaban dengan operator 'and'.

💡

Output (Resolusi)

Mengembalikan (return) rekomendasi presisi.

Sesi 6: Tahap Pembuatan (1)

Tahap 1: Membangun Mesin Inferensi (Fungsi)

Langkah awal adalah membangun logika kognitif program (Fungsi). Fungsi ini diletakkan di baris paling atas agar siap dipanggil oleh program utama kapan saja.

sistem_pakar.py (Bagian 1) 
# --- BLOK MESIN INFERENSI KECERDASAN ARTIFISIAL ---

def mesin_inferensi_minat(logika, fisik, seni):
    # Evaluasi kombinasi multivariabel menggunakan operator 'and'
    if logika == "Ya" and fisik == "Tidak" and seni == "Tidak":
        return "Rekomendasi Mutlak: Klub Pemrograman & Robotika."
    elif logika == "Tidak" and fisik == "Ya" and seni == "Tidak":
        return "Rekomendasi Mutlak: Akademi Olahraga (Atletik/Basket)."
    elif logika == "Tidak" and fisik == "Tidak" and seni == "Ya":
        return "Rekomendasi Mutlak: Sanggar Kesenian & Teater."

Sesi 6: Ketahanan Sistem

Pengembangan Toleransi Galat Berbasis String

Program saat ini rentan mengalami kegagalan logika apabila pengguna mengetik "ya" (huruf kecil) atau " YA " (dengan spasi). Kita perlu menerapkan metode normalisasi string (String Normalization) di area input.

Metode Pembersihan Teks (Robustness)

# Metode .strip() akan membuang spasi tidak sengaja di awal/akhir
# Metode .capitalize() memastikan huruf pertama selalu kapital
tanya_1 = input("Ketik Ya/Tidak: ").strip().capitalize()

# Jika pengguna mengetik "  ya   " 
# Python akan membersihkannya dan menyimpannya sebagai "Ya"
# Sehingga logika if tanya_1 == "Ya" akan tetap berfungsi sempurna.
Sesi 6: Penanganan Eksepsi

Penanganan Galat Dinamis (Try - Except)

Dalam skenario di mana sistem menuntut konversi tipe data angka (misal menghitung nilai rapor), input berupa huruf akan seketika menghancurkan program (ValueError).

Sebagai wawasan tambahan bagi pendidik, blok try...except adalah perisai pelindung yang meredam penghentian paksa sistem.

try:
    # Program MENGUJI kelayakan baris ini
    nilai_matematika = int(input("Masukkan Angka: "))
    print(f"Data valid: {nilai_matematika}")

except ValueError:
    # Apabila gagal, sistem TIDAK crash, melainkan:
    print("Galat Input: Sistem menolak karakter abjad.")
    print("Mohon ulangi menggunakan nomor presisi.")
