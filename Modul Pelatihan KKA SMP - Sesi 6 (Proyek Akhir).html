Sesi 6: Tujuan Pembelajaran

Tujuan Proyek Akhir

Proyek ini bertujuan untuk mengukur keberhasilan pelatihan dengan merangkai seluruh kompetensi dari sesi sebelumnya menjadi satu kesatuan program utuh. Aspek yang dinilai meliputi:

  • Sesi 1: Penerapan pedagogi pemecahan masalah (pembuatan alur sebelum penulisan kode).
  • Sesi 2: Penggunaan variabel, fungsi input(), pemformatan teks, dan konversi tipe data.
  • Sesi 3: Penerapan logika percabangan bersyarat (If-Elif-Else) yang akurat.
  • Sesi 4: Pemanfaatan perulangan (While Loop) untuk menjalankan program secara terus-menerus.
  • Sesi 5: Penerapan modularitas menggunakan fungsi (def) dan pengembalian nilai (return).
Sesi 6: Deskripsi Aplikasi

Spesifikasi Aplikasi Asisten Akademik

Kita akan merancang program sederhana yang relevan dengan tugas guru sehari-hari, yaitu program pengolahan nilai siswa.

Alur Kerja Program:

  1. Sistem meminta data nama siswa, nilai tugas, dan nilai ujian.
  2. Sistem menghitung nilai rata-rata melalui sebuah fungsi matematika.
  3. Sistem menentukan predikat huruf (A/B/C/D) melalui fungsi logika.
  4. Sistem menampilkan laporan hasil belajar ke layar.
  5. Sistem menawarkan opsi untuk memproses siswa lain (mengulang alur dari awal) atau keluar dari program.

Sesi 6: Penulisan Kode (1)

Tahap 2: Menyusun Fungsi Hitung Rata-rata

Langkah pertama dalam penulisan kode adalah membuat fungsi komputasi. Letakkan seluruh blok fungsi di bagian paling atas dokumen kode program.

sistem_akademik.py (Bagian 1) 
# --- BLOK PEMBUATAN FUNGSI ---

# Fungsi 1: Menghitung nilai rata-rata dari dua parameter masukan
def hitung_rata_rata(nilai1, nilai2):
    total = nilai1 + nilai2
    rata_rata = total / 2
    return rata_rata # Mengembalikan hasil ke pemanggil fungsi
Sesi 6: Penulisan Kode (2)

Tahap 3: Menyusun Fungsi Penentuan Predikat

Fungsi kedua memanfaatkan materi percabangan bersyarat untuk menentukan predikat kelulusan berdasarkan angka rata-rata.

sistem_akademik.py (Bagian 2) 
# Fungsi 2: Menggunakan Logika Percabangan (If-Elif-Else)
def tentukan_predikat(nilai_akhir):
    if nilai_akhir >= 90:
        return "A (Sangat Baik)"
    elif nilai_akhir >= 75:
        return "B (Tuntas)"
    elif nilai_akhir >= 60:
        return "C (Perlu Bimbingan)"
    else:
        return "D (Wajib Remedial)"
Sesi 6: Penulisan Kode (3)

Tahap 4: Mengawali Alur Program Utama (Perulangan)

Setelah fungsi siap digunakan, kita menyusun alur program utama. Kita menggunakan fungsi while agar program siap menerima data beberapa siswa sekaligus secara berkelanjutan tanpa perlu dijalankan ulang.

sistem_akademik.py (Bagian 3) 
# --- BLOK PROGRAM UTAMA ---
print("=== APLIKASI ASISTEN AKADEMIK ===")

# Variabel pengontrol perulangan
status_aplikasi = "berjalan"

# Perulangan utama program
while status_aplikasi == "berjalan":
    # (Kode penerimaan input akan berada di sini)
Sesi 6: Penulisan Kode (4)

Tahap 5: Menerima Masukan Pengguna (Input)

Di dalam blok perulangan while, masukkan perintah untuk meminta data dari pengguna. Perhatikan keharusan menggunakan konversi tipe data (float) untuk nilai angka.

sistem_akademik.py (Bagian 4) 
while status_aplikasi == "berjalan":
    print("\n--- Formulir Masukan Data Siswa ---")
    nama = input("Ketikkan Nama Siswa: ")
    
    # Mengonversi format teks menjadi angka desimal (float)
    nilai_tugas = float(input("Masukkan Nilai Tugas: "))
    nilai_ujian = float(input("Masukkan Nilai Ujian: "))
    
    # Memanggil Fungsi yang telah dibuat sebelumnya
    hasil_rata2 = hitung_rata_rata(nilai_tugas, nilai_ujian)
    hasil_predikat = tentukan_predikat(hasil_rata2)

Langkah terakhir adalah menampilkan kesimpulan evaluasi kepada pengguna menggunakan format interpolasi teks (F-String), kemudian memberikan mekanisme bagi pengguna untuk menghentikan program.

    # Menampilkan Laporan Hasil
    print("\n--- HASIL EVALUASI ---")

    # Mekanisme Menghentikan Perulangan

Sesi 6: Latihan Modifikasi

Latihan Modifikasi Kode Program (Tweak)

Latihan Praktik Kelas:

Setelah program dasar berhasil dijalankan, instruksikan peserta untuk melakukan penyesuaian fungsional:

  1. Tambahkan komponen nilai ketiga, misalnya: nilai_sikap.
  2. Sesuaikan parameter pada fungsi hitung_rata_rata untuk menerima dan memproses 3 buah angka.
  3. Tampilkan komponen baru tersebut pada hasil cetak laporan evaluasi akhir.
Sesi 6: Identifikasi Galat

Identifikasi Pesan Kesalahan Terpadu (Debugging)

Saat melakukan modifikasi pada kode yang komprehensif, peserta didik mungkin akan menemui kendala berlapis. Fasilitator harus membantu mengidentifikasi akar permasalahannya.

Tampilan Pesan Kesalahan (Galat)Akar Permasalahan (Diagnosis)
TypeError: hitung_rata_rata() takes 2 positional arguments but 3 were givenPeserta memasukkan 3 nilai saat memanggil fungsi, tetapi di bagian deklarasi fungsi (def) hanya terdapat 2 parameter.
ValueError: could not convert string to floatPengguna mengetikkan abjad atau huruf pada permintaan input yang secara khusus dikonversi menggunakan float().
Sesi 6: Pengayaan Materi

Materi Pengayaan Lanjutan: Penanganan Galat Dinamis

Program yang dirancang dengan baik tidak akan langsung tertutup secara paksa (*crash*) hanya karena satu kesalahan input dari pengguna.

Sebagai materi pengayaan bagi siswa yang telah menguasai logika dasar, guru dapat memperkenalkan blok struktur kontrol penanganan kesalahan menggunakan perintah try dan except ValueError.

Fitur ini akan mencegah program berhenti saat pengguna mengetik huruf di kolom angka, dan justru akan memberikan peringatan kepada pengguna untuk memperbaiki ketikannya.
