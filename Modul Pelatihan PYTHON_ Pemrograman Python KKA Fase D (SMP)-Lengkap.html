Sesi 2: Praktik

Praktik Keluaran Layar: fungsi print()

Fungsi print() adalah modul absolut untuk mengomunikasikan teks ke pengguna akhir.

  • Teks (String) wajib dideklarasikan di dalam tanda kutip tunggal '...' atau ganda "..." secara sekuensial.
  • Fungsi print() secara bawaan (default) akan menambahkan pergantian baris (Enter) di setiap pemanggilannya.

print("Modul Sistem KKA Aktif")

# Angka tidak memerlukan kutip

Sesi 2: Fondasi

Aturan Penulisan Sintaks Dasar

Kaidah utama dalam menulis kode Python di kelas SMP:

  1. Sensitivitas Huruf (Case Sensitive): Penulisan Print() dengan huruf kapital 'P' adalah salah. Semua fungsi bawaan menggunakan huruf kecil.
  2. Konsistensi Kutipan: Membuka teks dengan kutip ganda " harus diakhiri dengan kutip ganda ". Mencampurkan kutipan (seperti "Teks') akan memicu galat sintaksis.
  3. Pembatas Blok: Python mengandalkan garis baris baru (Enter) sebagai akhir dari sebuah instruksi tunggal.

Sesi 2: Praktik

Perbedaan Penggabungan: Koma vs Tambah

Metode Simbol Koma (,)

Secara otomatis menyisipkan jarak satu spasi pemisah di antara setiap argumen.

user = "Andi"
print("Halo", user)
# Hasil: Halo Andi

Metode Simbol Tambah (+)

Penggabungan presisi murni tanpa ruang spasi tambahan (harus disisipkan manual secara literal).

user = "Andi"
print("Halo " + user)
# Hasil: Halo Andi

Mengapa Identifikasi Tipe Data Krusial?

Dalam bahasa komputasi murni, simbol angka "100" belum tentu dipahami sebagai nilai matematis yang dapat dikalikan. Komputer merespons secara spesifik berdasarkan klasifikasi *Tipe Data* yang mendasari informasi tersebut.

Tipe Data Numerik murni: Integer & Float

Integer (int)

Sesi 3: Fondasi Kompleks

Konversi Eksplisit Tipe Data (Casting)

Data yang dikumpulkan dari pengguna melalui fungsi input() akan selalu berklasifikasi Tipe Data String secara bawaan. Memanipulasi nilai ini tanpa konversi akan berakibat galat eksekusi.

Metode Pembungkusan Konversi:

  • int() mengonversi teks literal berformat angka bulat menjadi nilai matematis utuh.
  • float() mengonversi teks ke format angka pecahan.
  • str() memaksa konversi nilai numerik menjadi teks format bebas untuk digabungkan dengan kalimat lain.

Sesi 3: Operasi Khusus

Operator Lanjutan: Modulo dan Pembagian Bulat

Bahasa pemrograman modern memfasilitasi algoritma analisis numerik spesifik tingkat menengah:

Modulo (%)

Digunakan untuk mengambil nilai SISA BAGI murni dari operasi matematis. Sangat esensial untuk memeriksa angka yang berstatus ganjil atau genap.

10 % 3 
# Menghasilkan 1 (10 dibagi 3 sisa 1)

Pembagian Bulat (//)

Pengembalian hasil pembagian utuh yang mengeliminasi pembulatan pecahan.

10 // 3
# Menghasilkan 3 (angka di belakang koma dibuang)

Dalam hierarki eksekusi absolut, komputer mengeksekusi instruksi dari baris atas secara tegak lurus (linear). Akan tetapi, penerapan blok pemrograman bersyarat (Conditional Statements) menginstruksikan sistem melakukan interupsi logika dan hanya menjalankan baris yang lolos seleksi kelayakan kondisi.

Sesi 4: Konsep Dasar

Tipe Data Boolean Fundamental

Pilar utama instruksi pengkondisian bersandar pada format Tipe Data Boolean yang diklasifikasikan ke dalam 2 resolusi absolut:

True (1)

Status logika Benar / Kondisi terpenuhi mutlak.

False (0)

Status logika Salah / Kondisi tidak memenuhi standar resolusi.

Sistem membedakan huruf besar secara spesifik: Wajib menggunakan huruf kapital 'T' dan 'F' (sebagai True / False).

Sesi 5: Konsep Awal

Prinsip D.R.Y (Don't Repeat Yourself)

Fondasi rekayasa perangkat lunak mengedepankan otomasi sistem. Jika terdapat tiga atau lebih baris komando sistematis yang seragam dan diulang ketik manual, sistem tersebut dikategorisasikan tidak matang secara algoritma. Python menyajikan blok pengulang statis dan dinamis.

Sesi 5: Klasifikasi Loop

Format for menginstruksikan siklus yang batas akhir iterasi (perulangan) nya diketahui atau telah dideklarasikan secara absolut pada objek urut-urutan (sequence), kumpulan parameter angka, atau jumlah huruf karakter (String).

Sesi 5: Elemen Krusial While

Konsep Batasan Modifikasi (Exit Condition)

Struktur `while` wajib memboyong sintaks pembaruan (Update) kondisi di dalam pelukan blok margin terdalamnya. Ketiadaan *decrement* atau *increment* nilai pengecekan akan secara mutlak melahirkan Galat Infinite Loop atau perulangan tak terbatas yang dapat merusak alokasi *RAM/Memory* komputasi lokal perangkat Anda.

print(f"\n[AI-System-Report] -> {hasil_analitik}")

Parameter (Daging Mentah) dimasukkan ke dalam modul mesin, dan akan dikeluarkan lewat pipa Return (Sosis Matang).
